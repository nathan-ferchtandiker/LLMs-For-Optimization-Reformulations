# Autonomous Optimization Model Generator

**What can this tool do?**

This tool leverages Large Language Models (LLMs) to identify and improve inefficiencies in an optimization model by identifying and implementing models that are equivalent and computationally more efficient. New formulations are generated by analyzing modeling assumptions present in the inefficient model and checking in the problem context, if these assumptions need to hold. As an example, consider the case below:

The goal is to choose up to p new hospital locations from a list of possible sites, in order to serve as many
people living in nearby neighborhoods. A neighborhood is considered served if they are assigned to a
hospital that is no more than S units away from their home. There are already M hospitals open, which
must remain open.

## Methodology

![Stage 1](Stage1.png)
In the first stage, a problem description in natural language, an optimization in LaTeX and the data of the optimization problem is fed to the LLM. The LLM then proceeds to standardize the format of the optimization model by creating a cononical version of the formulation. 

In addition, a synthetic data geerator is created. In essence, this is a piece of Python code that samples data to replicate the large problem data on a smaller scale. Various smaller scale datasets are leveraged during the second stage of the pipeline in which an equivalence between proposed models and the original model is checked.


![Stage 2](Stage2.png)
The second stage of the pipeline generates several candiate formulations which are checked for performance gains and equivalence to the original model. To generate alternative formulations, the modeling assumptions are extracted by the LLM. In addition, the LLM checks for each assumption, if the problem context states that it needs to hold. In the next step, the assumptions serve basis for new canonical formulations. Finally, to asses the correctness of the new formulations, several checks are applied to verify that the new formulations are faster and equivalent.

## How to Get Started

1. **Clone the repository** (download the code)
2. **Install the required software**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Get an OpenAI API key** (for the model-building features):
   - Sign up at [OpenAI](https://platform.openai.com/)
   - Create a `.env` file in the project folder and add your key:
     ```
     OPENAI_API_KEY=your_api_key_here
     ```
4. **Get a Gurobi license** (free for academics, see [Gurobi website](https://www.gurobi.com/))

---

## How to Use the Project

1. **Describe your problem**
   - In the `src/datasets/your_problem/` folder, add:
     - `detailed description.txt`: Write what you want to solve (in plain English)
     - `inefficient model.tex`: (Optional) If you have a math version, put it here (LaTeX format)
     - `dataset_description.txt`: Describe what kind of data is needed (e.g., list of locations, costs)
     - `large_data.json`: (Optional) Example data for your problem

2. **Run the main program**:
   ```bash
   python -m src.pipeline.main
   ```
   (Or, for older scripts: `python src/main.py`)

3. **What happens next?**
   - The program will:
     1. Read your problem and data
     2. Build a model and create test data
     3. Solve the model with Gurobi
     4. Analyze and suggest improvements
     5. Try out improved models and compare results
     6. Save everything in the `trials/` folder

---

## Project Structure (What's in Each Folder?)

- `models/`: Defines the building blocks for problems and solutions
- `llm/`: Handles all model-building and analysis tasks
- `utils/`: Helper functions for checking data, solving, and comparing models
- `pipeline/`: The main workflow (start here!)
- `datasets/`: Where you put your problem descriptions and data
